# Luach Moadim – Jewish Calendar Events

> A free, static web app for adding annual Jewish calendar events to any calendar application.

🌐 **Live site:** https://erezdaniel7.github.io/luach-moadim

---

## What is it?

**Luach Moadim** lets you enter Hebrew-date events— Yahrtzeits, Hebrew birthdays, anniversaries, memorials — and export them as a file you can import into **Google Calendar, Outlook, Apple Calendar**, or any other calendar app that supports ICS/CSV.

All generated calendar events include the Hebrew date in their description plus a "Generated by" attribution linking back to this app.

---

## Features

| Feature | Details |
|---|---|
| ✡️ Hebrew date entry | Select day & month by Hebrew name |
| 💾 Persistent storage | Events saved in browser `localStorage` – no server |
| ✅ Selective export | Checkbox per event; include/exclude as needed |
| 📅 ICS export (default) | RFC 5545-compliant; works with all major calendar apps |
| 📊 CSV export | Google Calendar–compatible format |
| 🔁 Multi-year generation | Default 50 years, configurable 1–200 |
| 🕍 Leap-year aware | Handles Adar / Adar I / Adar II correctly |
| 📝 Event attribution | Each event description includes Hebrew date + "Generated by" link |
| 📱 Responsive | Works on desktop & mobile |
| 🌐 Hebrew UI (RTL) | Fully right-to-left Hebrew interface |

## How to Use

1. Open the app: https://erezdaniel7.github.io/luach-moadim
2. Type the **event name** (e.g. "Yahrzeit for Dad").
3. Select the **Hebrew month** and **day**.
4. Click **הוסף אירוע** (Add Event). The next occurrence date is shown as confirmation.
5. Repeat for all events you want to track.
6. In the export section, set the **number of years** (default: 50).
7. Click **הורד קובץ ICS** (Download ICS File).
8. Import the file into your calendar (see instructions below).

---

## Importing into Google Calendar

1. Click **הורד קובץ ICS** → file saved as `luach-moadim.ics`.
2. Open [Google Calendar](https://calendar.google.com).
3. Click the ⚙️ gear icon → **Settings**.
4. In the left sidebar click **Import & Export**.
5. Click **Select file from your computer** → choose `luach-moadim.ics`.
6. Click **Import**. Done! 🎉

## Importing into Outlook (Desktop)

1. File → Open & Export → Import/Export
2. Choose **Import an iCalendar (.ics) file** → Next
3. Select `luach-moadim.ics` → OK

## Importing into Apple Calendar

1. Calendar app → **File → Import…**
2. Select `luach-moadim.ics` → Import → choose the target calendar → OK

**iPhone/iPad:** Send the `.ics` file to yourself by email, open it on the device, tap the attachment → **Add to All Calendars**.

## Hebrew Date Handling

| Scenario | Behaviour |
|---|---|
| **Adar** (month 7) | Regular Adar in non-leap years; Adar II in leap years |
| **Adar I** (month 6) | Falls back to **Adar** in non-leap years (so birthdays & Yahrtzeits are never skipped). A note is added to the event description when this happens. |
| **Day 30 in a short month** | Event observed on the last day of the month (day 29) with a note in the description |

## Event Description Format

Every exported calendar event contains a description in this format:

```
תאריך עברי: כ"ז תמוז ה'תשפ"ה
נוצר ע"י לוח מועדים | https://erezdaniel7.github.io/luach-moadim
```

When an Adar I event falls back to Adar in a non-leap year:

```
תאריך עברי: כ' אדר ה'תשפ"ו (אדר א' – הוזז לאדר כי שנה זו אינה שנת עיבור)
נוצר ע"י לוח מועדים | https://erezdaniel7.github.io/luach-moadim
```

## Technical Details

- **Pure HTML/CSS/JavaScript** — no build tools, no frameworks, no server
- Uses [HeDate.js](https://github.com/erezdaniel7/he-date) (MIT) for all Hebrew↔Gregorian date calculations
- ICS output: RFC 5545 compliant, `DTSTART;VALUE=DATE` all-day events, UTF-8
- CSV output: Google Calendar import format with UTF-8 BOM for Hebrew character support
- All data lives in `localStorage` — zero network requests after initial page load
